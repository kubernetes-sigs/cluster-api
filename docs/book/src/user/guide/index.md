# User Guide

This section provides details for some of the operations that need to be performed
when managing providers and clusters.

- [Managing Providers](./providers/index.md): installing, upgrading and operating
  Cluster API providers.
- [Cluster Configuration](./configuration/index.md): choosing bootstrap and control
  plane providers, and configuring cluster creation and ClusterClass.
- [Addon Management](./addon-management/index.md): attaching and managing add-ons on
  workload clusters.
- [Cluster Lifecycle](./lifecycle/index.md): upgrading, updating and managing Machines
  over the lifetime of a cluster.
- [Security Guidelines](./security/index.md): guidelines to provision clusters which
  are secure by default.
- [Troubleshooting](./troubleshooting.md): diagnosing common issues encountered while
  following the Quick Start.
